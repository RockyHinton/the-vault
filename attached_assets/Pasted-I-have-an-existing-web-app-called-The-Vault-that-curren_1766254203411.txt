I have an existing web app called The Vault that currently manages film projects with basic file uploads. I want to evolve this system into a stage-aware production intelligence platform that mirrors how films are actually evaluated, developed (pre-production), and produced.

Do NOT rebuild from scratch.
Extend and restructure the current system logically.

Core Concept

Projects are no longer flat or equal.
Every project exists in one and only one stage at any time:

Evaluation

Development

Production

Archived (failed or paused projects)

The UI, available sections, and focus of each project change depending on its stage.

Global Project List Changes

Update the main project dashboard to:

Display project stage clearly

Allow filtering by:

Evaluation

Development

Production

Archived

Make it immediately obvious where attention is needed

Projects should be movable between stages via explicit actions, not drag-and-drop.

Project State Logic

Each project has:

stage field (Evaluation / Development / Production / Archived)

Full history preserved across stages

No data loss when moving stages

Moving a project forward:

Is intentional (button + confirmation)

Preserves all documents, notes, and metadata

Unlocks new tools and sections

Archiving:

Removes project from active workflows

Keeps all data searchable and readable

Allows revival later
